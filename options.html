Gemini Page Translator

Create a key at openrouter.ai/settings/keys and keep some credit on it. It's stored only in this browser (chrome.storage.local) and sent only to OpenRouter. Every request asks OpenRouter for zero-data-retention providers that don't train on your text.

Prices are US$ per million tokens (input / output). If the chosen model fails (not a key or credit problem), a backup model answers automatically and the page pill shows which one did. You can also switch models from the pill on any translated page; it re-translates the page with the model you pick.

Get a key at aistudio.google.com/apikey. It's stored only in this browser (chrome.storage.local) and sent directly to Google — never to any other server.

Auto-translate sites

Pages on these sites translate on their own as they load. Add a site (freecodecamp.org) or just one section of it (freecodecamp.org/learn). Chrome asks once for permission to read pages on that site.

    Translation cache

    Every translated fragment is remembered on this machine, so revisiting a page (or hitting the same menu text across a site) costs nothing. The cache is per provider and model.
